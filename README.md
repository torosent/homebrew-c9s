# homebrew-c9s

Homebrew tap for [c9s](https://github.com/torosent/c9s) — Terminal UI for Apple Containers.

## Installation

```bash
brew tap torosent/c9s
brew install c9s
```

## Requirements

- Apple Silicon Mac (darwin/arm64)
- macOS recent enough to run the [Apple `container` CLI](https://github.com/apple/container)

## Updates

The cask is updated whenever a new c9s release is published. See the [c9s releases page](https://github.com/torosent/c9s/releases) for the version history.
